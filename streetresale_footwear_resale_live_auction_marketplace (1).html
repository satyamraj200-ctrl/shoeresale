HOW STREETRESALE WORKS

DUAL-ENGINE RESALE MARKETPLACE

Designed per the BCA Project Synopsis: Combining instant fixed-price shopping with a real-time validated auction engine.

1. Live Auction Bidding

Sellers set a starting price, minimum bid increment, and countdown timer. Server validates every bid before updating the highest bid.

2. Fixed-Price Instant Buy

Look for the ⚡ NOW badge to add sneakers directly to your cart and checkout immediately without waiting.

3. AJAX Live Bid Polling

Uses periodic JavaScript Fetch/AJAX polling to synchronize current highest bids and countdown timers without full page reloads.

4. Winner Auto-Selection

When an auction countdown reaches zero, bidding locks automatically and the highest bidder can complete their winning order checkout.

BCA Synopsis Architecture: Python Flask + SQLite Database Schema

Matches your 4 primary database entities (users, listings, bids, orders) & server-side bid validation

// 1. SQLite Database Entities (users, listings, bids, orders)

CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT UNIQUE NOT NULL,
    email TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    role TEXT DEFAULT 'buyer_seller'
);

CREATE TABLE listings (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    seller_id INTEGER NOT NULL,
    brand TEXT NOT NULL,
    title TEXT NOT NULL,
    size TEXT NOT NULL,
    condition TEXT NOT NULL,
    listing_type TEXT CHECK(listing_type IN ('fixed', 'auction')) NOT NULL,
    price INTEGER NOT NULL,
    current_bid INTEGER DEFAULT 0,
    min_increment INTEGER DEFAULT 500,
    end_time DATETIME,
    status TEXT DEFAULT 'active'
);

CREATE TABLE bids (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    listing_id INTEGER NOT NULL,
    bidder_id INTEGER NOT NULL,
    bid_amount INTEGER NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE orders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    listing_id INTEGER NOT NULL,
    buyer_id INTEGER NOT NULL,
    final_amount INTEGER NOT NULL,
    payment_method TEXT NOT NULL,
    order_status TEXT DEFAULT 'Confirmed'
);
